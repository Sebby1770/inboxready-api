What exactly does an audit check?Product

MX routing, SPF (including syntax and lookup pressure), DKIM for the selectors you supply, DMARC policy and alignment, MTA-STS, TLS-RPT, and BIMI. Each check returns a pass, warn, fail, or info status with its own remediation text, and the checks roll up into a single weighted score out of 100.

Is this a full DMARC analytics platform?Product

No, and that is deliberate. Aggregate-report processing is a different, heavier product. InboxReady answers the question that blocks activation today: is this domain configured correctly right now, and if not, what record is missing?

How long does it take to integrate?Integration

One POST and a score comparison — most teams have the audit rendering in their onboarding wizard inside an afternoon. The response is deliberately flat and machine-readable so you can drive UI decisions straight from it.

Do I need an API key to try it?Integration

Not locally. Leave INBOXREADY_API_KEYS empty and the instance is open for development. In production, set the key list — the X-API-Key header then becomes mandatory on every /v1 route and drives per-key rate limiting.

What do you store about the domains I audit?Data

By default, nothing leaves the process. Audit history is in-memory unless you set INBOXREADY_HISTORY_PATH, in which case it is written to a file on your own instance. There is no third-party analytics on API responses. See the privacy policy for the full picture.

Does an audit send email or touch my customers?Data

No. Every check is a public DNS lookup plus, for MTA-STS and BIMI, a fetch of a policy file the domain owner published deliberately. Nothing is delivered to a mailbox and no mail flow is affected.

How fast will someone answer me?Support

Within one business day, Monday to Friday, Melbourne time. Suspected outages jump the queue — and /healthz and /readyz will tell you instantly whether the service itself is the problem.

What happens if I go over my plan's audit volume?Pricing

Nothing breaks mid-month. Overage is billed at the plan's rate rather than being hard-stopped, because an audit usually fires at the exact moment a customer is trying to activate — a 402 there costs you far more than the overage does.
