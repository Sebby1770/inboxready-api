The gate

When the answer is “not yet”, it says what is in the way

The readiness check is deliberately conservative. It needs enough volume to judge, a high aligned pass rate, and no meaningful source still failing. Forwarding never blocks a rollout, because forwarded mail with an aligned signature already passes DMARC.

Handling

What we do with an uploaded report

Parsed, summarised, discarded

Reports are read in memory to build the response and are not written to disk or retained afterwards. See the privacy policy.

Treated as untrusted input

Anyone can email you a report, so uploads are bounded on compressed size, decompressed size, member count, and record count, and any file declaring a DTD or XML entities is refused rather than parsed.

No personal content

Aggregate reports carry sending IPs, volumes, and authentication results. They do not contain message bodies, subjects, or recipient addresses.
