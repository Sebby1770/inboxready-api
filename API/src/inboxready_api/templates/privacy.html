Legal

Privacy policy

Last updated {{ last_updated }}. Written to be read, not to be survived.

The short version

  • Auditing a domain queries public DNS. We do not need, and do not ask for, mailbox access.
  • Audit results are not retained by default. History is opt-in and stays on your instance.
  • The contact form is used to reply to you. It is not fed into a marketing list.
  • Analytics is off unless a measurement ID is configured, and then only after you consent.

Who is responsible

{{ org.legal_name }}, {{ org.address.single_line }}, is the controller for personal data described here. Reach us at {{ org.email }}.

What we collect, and why

When you use the API or the workspace

  • The domain you audit. A domain name is not usually personal data, but it can be (a sole trader's surname, for example). It is processed to run the checks and is discarded when the response is returned, unless history persistence is enabled on the instance you are calling.
  • Your IP address. Held transiently in memory for rate limiting. It is not written to disk by the application and is not used to profile you.
  • Your API key, if you send one. Used to authenticate the call and to bucket rate limits.

When you contact us

  • Your name, email address, optional company, chosen topic, and message.
  • Used solely to answer you and to keep a record of the conversation.

When you browse the site

  • Analytics runs only if a Google Analytics 4 measurement ID is configured for the deployment. Where consent is required, no analytics cookie is set and no event is sent until you accept the banner. Declining is remembered, and re-declining later clears the choice.
  • One first-party item is stored in your browser regardless: the list of domains you recently audited, kept in localStorage so the workspace can offer them back to you. It never leaves your device and clearing site data removes it.

Lawful basis (UK/EU GDPR)

  • Contract — providing the API you or your employer signed up for.
  • Legitimate interests — rate limiting and abuse prevention, balanced against the minimal, transient data involved.
  • Consent — analytics cookies, and nothing else.

How long we keep things

  • Audit responses: not retained, unless the operator of the instance enables history.
  • Rate-limit counters: a rolling 60-second window, in memory only.
  • Contact messages: kept while the conversation is useful, then deleted on request.
  • Analytics: whatever retention the account is configured for, capped at 14 months.

Who else sees it

Google Analytics, if enabled and consented to. The hosting provider running the instance. Nobody else — there is no data broker, no enrichment service, and no advertising pixel on this site.

Your rights

Access, correction, erasure, restriction, portability, and objection. Email {{ org.email }} and we will action it within 30 days. Australian users may also complain to the OAIC; EU and UK users to their local supervisory authority.

If you self-host

This project is source-available. When you run your own instance, you are the controller for everything it processes, and this policy describes the software's behaviour rather than your obligations. Our security page covers the technical side.

Changes

Material changes will be dated at the top of this page. The repository history is the audit trail.
