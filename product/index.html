What we check

Each check answers one question a customer can act on

MX

MX routing

Can anyone deliver mail to this domain at all?

Resolves the MX record set and reports the hosts in preference order. A domain with no MX cannot receive replies, bounces, or DMARC reports.

SPF

SPF

Which servers are allowed to send as this domain?

Parses the TXT policy, flags multiple conflicting records, a soft ~all where -all was intended, and include chains pushing the ten-lookup limit.

DKIM

DKIM

Is outbound mail cryptographically signed?

Looks up each selector you supply at selector._domainkey and reports which ones publish a usable public key.

DMARC

DMARC

What should a receiver do when authentication fails?

Reads _dmarc, reports the policy, and warns when it is still parked at p=none — monitoring is not enforcement.

MTA-STS

MTA-STS

Is TLS enforced for inbound mail?

Checks the _mta-sts TXT record and fetches the published policy file over HTTPS to confirm the mode and the MX list agree.

TLS-RPT

TLS-RPT

Will you hear about TLS failures?

Confirms _smtp._tls publishes a reporting destination so downgrade attempts surface.

BIMI

BIMI

Is the brand logo eligible to appear in the inbox?

Checks the default._bimi record and its logo and certificate references. Informational — BIMI needs enforcing DMARC first.

Scoring

The score is weighted, documented, and queryable

Weights are not a secret sauce. GET /v1/scoring returns them as JSON so you can show a customer why their domain sits where it does.

cURL

Request an audit

curl -X POST https://api.inboxready.dev/v1/audits/email-domain \
  -H "Authorization: Bearer $INBOXREADY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "domain": "customer-example.com",
    "selectors": ["google", "selector1"],
    "expected_providers": ["Google Workspace"]
  }'

JavaScript

Gate a step on the result

const response = await fetch("/v1/audits/email-domain", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    domain: "customer-example.com",
    selectors: ["google", "selector1"]
  })
});

const audit = await response.json();
console.log(audit.score, audit.recommendations);
